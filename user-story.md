# User Stories for Fullstack Capstone Project

## User Story 1: User Registration
**As a** new user  
**I want to** create an account with email and password  
**So that** I can access the application features

**Acceptance Criteria:**
- [ ] User can enter email, password, and name
- [ ] System validates email format
- [ ] System shows error if email already exists

## User Story 2: User Login
**As a** registered user  
**I want to** log in to my account  
**So that** I can access my dashboard

**Acceptance Criteria:**
- [ ] User can enter email and password
- [ ] System shows error for invalid credentials
- [ ] User is redirected to dashboard after login

## User Story 3: View Items
**As a** user  
**I want to** view the list of items  
**So that** I can browse available options

**Acceptance Criteria:**
- [ ] Items are displayed in a list/grid
- [ ] Each item shows name, description, and price
- [ ] User can search for items

## User Story 4: Add Item to Cart
**As a** user  
**I want to** add items to my cart  
**So that** I can purchase them later

**Acceptance Criteria:**
- [ ] User can click "Add to Cart" button
- [ ] Cart count increases
- [ ] User can view cart items

## User Story 5: Place Order
**As a** user  
**I want to** place an order  
**So that** I can buy the items in my cart

**Acceptance Criteria:**
- [ ] User can proceed to checkout
- [ ] Order confirmation is shown
- [ ] Cart is cleared after order

## User Story 6: View Order History
**As a** user  
**I want to** see my past orders  
**So that** I can track my purchases

**Acceptance Criteria:**
- [ ] User can view list of past orders
- [ ] Each order shows date, items, and total
- [ ] User can click to see order details

## User Story 7: Update Profile
**As a** user  
**I want to** update my profile information  
**So that** my account details are current

**Acceptance Criteria:**
- [ ] User can edit name, email, and password
- [ ] Changes are saved successfully
- [ ] User sees confirmation message

## User Story 8: Logout
**As a** user  
**I want to** log out of my account  
**So that** my account remains secure

**Acceptance Criteria:**
- [ ] User can click logout button
- [ ] User is redirected to login page
- [ ] Session is cleared
